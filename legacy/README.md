# legacy/ — React+Vite parity reference

Původní React + Vite + react-router verze jazumaliving.com. **Není součástí
Astro buildu** ani CI (vyloučeno v `tsconfig.json` a `eslint.config.js`).

Slouží jako **parity reference** při migraci na Astro 5 (větev `astro-rebuild`,
Fáze 4 dle `SPEC-Lite-Jazuma.md`): z těchto souborů se portují data, komponenty
a logika do nové struktury `src/`. Plná historie je zachována na větvi `main`.

Po dokončení migrace a zelené Fázi 5 bude tato složka odstraněna (samostatné
schválení).
